# SLO-контракт. Каталог

## SLI

| SLI | Определение | Источник измерения |
|---|---|---|
| Доступность | (успешные ответы 2xx/304 из приложения, CDN и серверного кеша) / (все запросы чтения каталога) за 5 мин | Prometheus: метрики ingress + CDN |
| Задержка | Доля запросов чтения каталога с ответом сервера < 300 мс | Prometheus histogram, P99 |
| Актуальность | Доля карточек товара, где цена в кеше не старше TTL (15 мин) | Метрика возраста кеша |

## SLO

| Показатель | Цель | Окно | Error budget |
|---|---|---|---|
| Доступность | 99% | 30 дней скользящее | 7,2 ч/мес |
| Задержка P99 < 300 мс | 99% запросов | 30 дней | 1% медленных |
| Актуальность цен | 99% в пределах TTL | 30 дней | - |

## SLA

- Каталог доступен покупателям 99% времени; при сбое БД - read-only режим из кеша/CDN (NFR-04)
- При сжигании error budget быстрее 2% в час отправляется алерт дежурному, при исчерпании бюджета на месяц - заморозка релизов каталога до разбора
- Исключения: плановые миграции БД (объявляются за 48 ч, вне пиковых часов нагрузки)
