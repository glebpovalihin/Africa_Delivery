# SLO-контракт. Платежи

В формате OpenSLO: [./payments.yaml](./payments.yaml)

## SLI

| SLI | Определение | Источник измерения |
|---|---|---|
| Доступность приема платежа | (успешно принятые к обработке платежи) / (все попытки инициации), ошибки валидации пользователя исключены | Prometheus: метрики платежного модуля |
| Завершение платежа | (платежи с финальным статусом < 5 мин) / (все инициированные) | Платежный журнал PostgreSQL |
| Задержка инициации | Доля инициаций с ответом < 2 с (без ожидания подтверждения провайдера) | Prometheus histogram, P95 |
| Целостность | 0 расхождений между платежным журналом и подтверждениями провайдера по итогам сверки | Ежедневная сверка (reconciliation job) |

## SLO

| Показатель | Цель | Окно | Error budget |
|---|---|---|---|
| Доступность приема платежа | 99,9% | скользящее окно в 30 дней | 43 мин/мес |
| Завершение < 5 мин | 98% (учитывает окна провайдеров) | 30 дней | - |
| Задержка инициации P95 < 2 с | 95% | 30 дней | - |
| Расхождения сверки | 0 | ежедневно | 0 |

## SLA

- Прием платежа доступен 99,9% времени. При недоступности провайдера происходит автоматический переход на резервного провайдера страны по circuit breaker: Нигерия - Paystack <-> Flutterwave; Кения на пилоте без резерва, покупателю показывается прозрачный статус, платеж ставится в очередь повторных попыток
- Отсутствует потеря платежей внутри региона - RPO платежного журнала = 0, повторная попытка безопасна из-за идемпотентности. При потере региона потери - до 15 мин (WAL-архив в Disaster Recovery eu-west-1), восстановление RTO 4-8 ч
- При сжигании error budget быстрее 5%/час - алерт P1 дежурному  + CFO: потерянный GMV считается по среднему чеку
- Исключения: полный даунтайм всех платежных провайдеров страны либо полный отказ региона af-south-1 является форс мажором, эскалация к CEO, заказ принимается в статусе "ожидает оплаты" с уведомлением
