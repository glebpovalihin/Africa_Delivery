# Quality Attribute Scenarios

## QAS-01. Отказ зоны доступности

| Поле | Значение |
|---|---|
| Source of stimulus | Инфраструктура облачного провайдера |
| Stimulus | Зона доступности с частью подов и репликой БД становится недоступна |
| Artifact | Контур заказа и оплаты |
| Environment | Продакшен, пиковая нагрузка распродажи (500 RPS) |
| Response | Трафик переключается на реплики в живой зоне автоматически, managed PostgreSQL переключает failover, пользовательские запросы повторяются клиентом прозрачно |
| Response measure | Недоступность контура < 5 мин, 0 потерянных заказов |

Покрывает: NFR-01, NFR-10. Паттерны: Retry+backoff, health based failover

## QAS-02. Недоступность платежного провайдера

| Поле | Значение |
|---|---|
| Source of stimulus | Внешний партнер (платежный провайдер) |
| Stimulus | API основного провайдера страны возвращает 5xx или не отвечает > 10 с |
| Artifact | Платежная оркестрация |
| Environment | Продакшен, рабочее время |
| Response | Circuit Breaker открывается после 3 подряд неудачных вызовов, платежи маршрутизируются на резервного провайдера, вошедшие платежи ставятся в очередь повторных попыток, покупатель видит статус "платеж обрабатывается" |
| Response measure | Доля платежей, потерянных из-за сбоя провайдера = 0,  завершение отложенных платежей < 5 мин после восстановления |

Покрывает: NFR-01, SLO платежей. Паттерны: Circuit Breaker, Retry + backoff, Queue Based Load Leveling.

## QAS-03. Пиковая нагрузка распродажи

| Поле | Значение |
|---|---|
| Source of stimulus | Покупатели, привлеченные маркетингом (артефакт 2) |
| Stimulus | Всплеск трафика x20 к среднему за 5 минут: 500 RPS чтения, 5 заказов/сек |
| Artifact | Каталог, оформление заказа, БД |
| Environment | Продакшен, неделя запуска |
| Response | Каталог обслуживается из CDN/кеша (hit ratio > 90%), HPA добавляет поды, запись заказов идет через БД без кеширования остатков |
| Response measure | P99 чтения < 300 мс, P99 заказа < 1,5 с, 0 ошибок статусов 5xx, масштабирование x5 < 15 мин |

Покрывает: NFR-06, NFR-08, NFR-09, NFR-15. Паттерны: Cache Aside, request coalescing, предпрогрев кеша

## QAS-04. Обрыв 3G на клиенте в момент оплаты

| Поле | Значение |
|---|---|
| Source of stimulus | Покупатель на нестабильной мобильной сети |
| Stimulus | Соединение рвется после инициации платежа, до получения ответа |
| Artifact | Мобильный клиент, платежный модуль |
| Environment | Продакшен, сети 3G/4G  |
| Response | Клиент при восстановлении связи опрашивает статус заказа по идемпотентному ключу, платеж не дублируется, статус подтверждается через смс |
| Response measure | Отсутствие двойных списаний, заказ восстанавливается в приложении после reconnect < 10 с, смс подтверждение < 60 с |

Покрывает: NFR-07, NFR-13. Паттерны - идемпотентность, дедупликация, мультиканальное подтверждение

## QAS-05. Недоступность SMS или USSD шлюзов

| Поле | Значение |
|---|---|
| Source of stimulus | Внешний партнер (SMS/USSD-агрегатор) |
| Stimulus | Шлюз недоступен 2 часа |
| Artifact | Уведомления, офлайн-заказы |
| Environment | Продакшен |
| Response | Очередь уведомлений накапливает события с retry, критичные (подтверждение оплаты) дублируются через пуши или WhatsApp, USSD-заказы получают ошибку с предложением повтора |
| Response measure | 0 потерянных событий, догоняющая доставка < 30 мин после восстановления, отсутствие повторных смс |

Покрывает: NFR-03, NFR-13. Паттерны: Queue-Based Load Leveling, Retry и backoff, дедупликация
