# Architecture Canvas

## Цели бизнеса

- 15.10.2026 - пилот в Нигерии и Кении: каталог 5000 SKU от 100 продавцов, заказ с оплатой M-Pesa и Flutterwave, уведомления смс/мессенджеры, ЛК покупателя, базовая аналитика для CEO
- через год - 5 стран, 1M+ пользователей, B2B, ЛК продавца с аналитикой, возвраты, локализация на 3 языка
- через 3 года - 12-15 стран, 40% рынка

## Ключевые драйверы

- Фиксированная дата запуска - медиа выкуплены, затраты не возвращаются
- Доступность "не падает": 1 мин простоя = $12k
- Локализация персональных данных: NDPR / POPIA / KICA, внимание регуляторов
- Бюджет: $5 тысяч/мес OPEX потолок
- Рынок: 100% мобильный трафик, 3G/4G, Android дешевле $150; 30-40% адресуемого рынка - только USSD/смс

## Ограничения

- 6 контракторов до декабря, найм заморожен
- Лицензионного ПО нет, без годовых предоплат и многолетних контрактов
- Прием платежей только через лицензированного провайдера
- Нет локальной ИТ-инфраструктуры и адресной системы, логистика через партнерские API
- В команде нет людей с локального рынка

## Риски

1. Ожидание 99,99% при бюджете $5 тысяч/мес - срыв ожиданий инвестора и авария в сезонные дни
2. Скоуп первого релиза не согласован, срыв даты или сырой запуск
3. Трансграничное хранение ПДн - санкции регулятора
4. Маркетинговые обещания не покрыты возможностями платформы и закона - репутационный удар.
5. Юридическое заключение будет через 4-6 недель - архитектура данных проектируется до его получения

## Допущения

- Дата важнее скоупа: MVP = цели пилота, остальное в roadmap
- Пиковая нагрузка запуска: до 50k DAU и около 2k заказов/день; точки расширения проектируем под 10M
- ПДн граждан Нигерии и Кении хранить в стране, аналитика на основе псевдонимов
- Купленная смс-база 410k не используется до решения юристов
